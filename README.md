# OGMinesweeper

A small Minesweeper replica made with Godot.

## Features

- Adjustable mine count
- Flagging
- Timer
- Win and loss detection

## Requirements

- Godot 4.x

## Running from source

1. Clone this repository.
2. Import `project.godot` into Godot.
3. Press F6 or F5 to run.
